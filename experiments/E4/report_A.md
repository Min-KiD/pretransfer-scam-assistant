# E4 giai đoạn A - Đọc ảnh chat ra JSON: baseline trên các bộ có sẵn

Không train gì ở giai đoạn này. Mỗi cấu hình chạy đúng một lần (không chạy lại để chọn kết quả tốt). Tỉ lệ ghi `tử/mẫu` và khoảng tin cậy Wilson 95%. `web` chia theo số thứ tự ảnh: lẻ là `web-dev` (được mở lỗi ra xem), chẵn là `web-test` (chỉ xem số). Chuỗi bịa = chuỗi model trả về mà không có trong đáp án, chia cho số chuỗi model trả về; chuỗi đáp án ghi ở `skipped` (bị che, mờ, bị cắt) hoặc `ignore` không tính.

Cấu hình: `A` = OCR CPU + regex; `T` = OCR/chữ + regex; `J` = ảnh -> JSON (ràng buộc); `Ju` = ảnh -> JSON (không ràng buộc); `O` = chữ OCR -> LLM -> JSON. `J__gemini-*` không có hậu tố `@low` là lần chạy của E1 (thinking mặc định).
